# Аналитический налоговый портал (ФНС)

Локально разворачиваемый портал: связывает **нормативные данные** (ставки и
льготы по имущественным налогам) со **статистической отчётностью** ФНС и даёт
по каждой территории профиль, таблицы, графики динамики, сравнение со средним
по субъектам и облака слов по формулировкам льгот.

Все данные связаны по трём измерениям: **год · регион · налог**.

```
┌──────────────────────────┐        ┌────────────────────────────┐
│ opendata 7707329152-     │        │ Формы статотчётности        │
│ taxrates (csv/xls/html)  │        │ 5-ТН и аналоги, по регионам │
│ ставки · льготы · НПА    │        │ (xls/xlsx, свой файл на год)│
└────────────┬─────────────┘        └───────────────┬────────────┘
             │ load-rates                           │ load-forms
             ▼                                      ▼
      rate / benefit ───────── SQLite ───────── fact_form
             │            год · регион · налог          │
             ▼                                          ▼
     облака слов (benefit_term)              сквозные показатели
             └───────────────► FastAPI + веб-интерфейс ◄┘
```

## Быстрый старт

### Вариант 1 — готовая программа для Windows (без установки Python)

1. Возьмите `fns-portal.exe`:
   * **со сборки в GitHub Actions** — вкладка *Actions* → последний запуск
     «Сборка Windows-версии» → раздел *Artifacts* → `fns-portal-windows`;
   * либо соберите сами одной командой: `build.bat` (нужен Python, ставится один раз),
     результат — `dist\fns-portal.exe`.
2. Положите exe в любую папку и **скиньте туда же выгрузки ФНС** — можно
   прямо россыпью или в подпапках (`формы\2024\...`).
3. Запустите exe.

При запуске программа:

* создаёт рядом с собой `data\` (база) и `reference\` (справочники, стоп-слова,
  алиасы колонок — их можно править);
* обходит свою папку, **сама определяет по содержимому**, что за файл —
  ставки и льготы или форма отчётности, — и загружает новые;
* уже загруженные файлы пропускает, так что повторный запуск быстрый;
* пересобирает словарь для облаков слов, если появились новые льготы;
* открывает браузер на `http://127.0.0.1:8000`.

Файлы можно докладывать в папку и просто перезапускать программу.
Если данных ещё нет, она предложит показать демонстрационный набор.

```bat
fns-portal.exe                     обычный запуск
fns-portal.exe --reimport          перечитать все файлы заново
fns-portal.exe --inspect           показать структуру файлов, не запуская портал
fns-portal.exe --no-browser        не открывать браузер
fns-portal.exe --port 8080         другой порт
fns-portal.exe --no-demo           не предлагать демо-данные
fns-portal.exe --update            установить обновление, не спрашивая
fns-portal.exe --no-update-check   не проверять обновления при запуске
```

**Обновления.** При каждом запуске программа сверяет свою версию с последней
сборкой и, если вышла новая, предлагает обновиться. Запущенный `.exe` нельзя
перезаписать, поэтому прежняя версия сохраняется рядом как `fns-portal.old.exe`
и удаляется при следующем запуске. Если сети нет — проверка молча
пропускается. Из исходников обновление идёт через `git pull` (см. ниже).

**Если файл не распознан.** Запустите `fns-portal.exe --inspect`: программа
покажет, что видит внутри каждого файла (кодировку, начало разметки, строки
таблиц, кандидатов в шапку и то, какие колонки распознаны), и сохранит рядом
`inspect-report.txt`. По отчёту видно, какие заголовки дописать в
`reference/column_aliases.json`.

Exe можно переименовать и переносить — рабочей всегда считается та папка,
где он лежит.

### Вариант 2 — из исходников

```bash
./run.sh                       # окружение, зависимости, демо-данные, сервер
# откройте http://127.0.0.1:8000
```

Windows (cmd) — то же самое одной командой:

```bat
run.bat
```

Вручную (cmd; в PowerShell активация — `.venv\Scripts\Activate.ps1`):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python -m fnsportal init          # создать БД + справочники + методичку 5-ТН
python -m fnsportal demo          # демонстрационные данные (см. ниже)
python -m fnsportal build-terms   # словарь для облаков слов
python -m fnsportal serve         # http://127.0.0.1:8000
```

На Linux/macOS вместо `.venv\Scripts\activate` — `source .venv/bin/activate`,
либо просто `./run.sh`.

`demo` создаёт **синтетический** набор с реальной структурой (те же показатели
формы 5-ТН, те же категории льготников), чтобы портал можно было посмотреть до
загрузки настоящих выгрузок. Реальные данные полностью замещают демо.

## Загрузка настоящих данных ФНС

### 1. Ставки и льготы (открытый набор)

Страница набора: <https://www.nalog.gov.ru/opendata/7707329152-taxrates/>

```bash
# посмотреть, какие файлы есть на странице набора
python -m fnsportal download rates --dry-run
python -m fnsportal download rates            # скачает в data/raw/rates (с докачкой)

# либо скачайте файлы вручную и загрузите (csv, xls, xlsx, html, zip, gz)
python -m fnsportal inspect data/raw/rates/data.html      # что за файл и какие колонки распознаны
python -m fnsportal load-rates data/raw/rates/data.html
python -m fnsportal build-terms                            # пересобрать облака слов
```

HTML-выгрузка (~3 ГБ) читается **потоком**: разбирается по одной строке
таблицы, в БД пишется пакетами по 20 000 записей. Память держится в районе
250 МБ независимо от размера файла, скорость — около 2,8 МБ/с, то есть файл на
3 ГБ загружается примерно за 20 минут; в консоли видно процент, число строк и
оценку оставшегося времени.

Сохранённая страница ФНС начинается с сотен служебных строк (меню, «хлебные
крошки»), поэтому шапка таблицы ищется в окне до 5000 строк — иначе файл
выглядел бы как «не ставки и не отчётность».

Одна строка выгрузки может дать и ставку, и льготу: если есть объект
налогообложения и размер ставки — пишется в `rate`, если категория/вид/размер
льготы — в `benefit`. Категория плательщика (**ФЛ / ИП / ЮЛ**) определяется по
явной колонке, а если её нет — по тексту категории (см. «Как определяется
категория»).

### 2. Формы статотчётности

Раздел на сайте УФНС (в адресе — код региона: `rn77`, `rn50`, …):
<https://www.nalog.gov.ru/rn77/related_activities/statistics_and_analytics/forms/>

```bash
python -m fnsportal download forms --regions 77 50 16 --years 2023 2024 --tax tn --dry-run
python -m fnsportal download forms --regions ALL --years 2024 --tax tn

# загрузка: год и регион определяются из имени файла/каталога/титульных строк
python -m fnsportal load-forms data/raw/forms/tn --tax tn
python -m fnsportal load-forms "data/raw/forms/tn/2019/*.xls" --tax tn --year 2019
python -m fnsportal load-forms файл.xls --tax tn --year 2006 --region 16   # если не определилось
```

Формы меняются от года к году, поэтому загрузчик ищет **коды строк**, а не
позиции, и переводит их в сквозные показатели по вашей методичке
(`reference/form_5tn_methodology.xlsx` → `reference/form_5tn_map.csv`):

* 2006 г. — юрлица и физлица в одной таблице, различаются **графы** (1 и 2);
* 2007–2010 гг. — коды `1xxx` / `2xxx`, 17 показателей;
* 2011–2025 гг. — 80–96 показателей, коды строк переезжают почти каждый год.

Из 20 лет методички **14 показателей сквозные за весь период** (итоги разделов
и разрезы по наземным/водным/воздушным ТС), ещё 58 — с 2011 года. Именно они
дают длинные динамические ряды.

Если методичка обновилась:

```bash
python -m fnsportal load-methodology reference/form_5tn_methodology.xlsx --tax tn
```

## Что умеет портал

| Экран | Содержание |
|---|---|
| **Обзор** | Итоговые показатели раздела за год, разбивка ЮЛ / ФЛ, отклонение от среднего по субъектам, место в рейтинге, график динамики |
| **Ставки** | Объект налогообложения, размер ставки, единица, плательщик, муниципалитет, условие, реквизиты НПА; фильтр по категории плательщика и поиск |
| **Льготы** | Карточки льгот с разделением **ФЛ / ИП / ЮЛ**: категория, вид льготы, размер, условие, основание, период действия, НПА |
| **Показатели формы** | Полная таблица формы по разделам: ЮЛ, ФЛ, всего, среднее по субъектам, «к среднему», ранг; отметка показателей → построение графика |
| **Аналитика** | Динамика за период, сравнение со средним по субъектам, рейтинг субъектов за год, структура показателей; выгрузка CSV |
| **Облака слов** | Частотный анализ формулировок льгот по категориям плательщиков, по выбранным регионам (или всем) и годам; режим «отличительные слова категории»; клик по слову → льготы с этим словом |

Состояние экрана хранится в адресной строке
(`#tax=tn&year=2023&region=50&tab=benefits`) — ссылку можно переслать.

Выгрузка CSV есть на каждом экране (`;` и BOM — Excel открывает корректно).

## Как определяется категория плательщика

Явная колонка «Плательщик»/«Категория налогоплательщика» имеет приоритет.
Если её нет, категория выводится из текста льготы:

* упоминание ИП в любом месте → **ИП** (самостоятельная группа льготников);
* иначе побеждает то упоминание, которое стоит раньше — в формулировках ФНС
  ведущее слово идёт первым: «Организации инвалидов» → **ЮЛ**,
  «Инвалиды I группы» → **ФЛ**;
* если признаков нет — категория `all` («без разделения»).

Сравнение идёт по основам слов (стеммер Портера), поэтому «физических лиц»,
«физическое лицо» и «физлица» распознаются одинаково. Если установить
`pymorphy3`, вместо стеммера используется полноценная лемматизация — портал
подхватит это автоматически (в шапке видно, какой режим активен).

## Как устроены облака слов

`build-terms` заранее считает частотный словарь по текстам льгот
(таблица `benefit_term`), поэтому облако строится мгновенно даже на миллионах
записей. При подсчёте:

* удаляются **общие стоп-слова** (`reference/stopwords_ru.txt`) и **типовые
  юридические клише** (`reference/stopwords_legal.txt`: «статья», «пункт»,
  «налоговый», «уплата», «установленный», «в соответствии» и т. п.) — списки
  правятся вручную, после правки достаточно перезапустить `build-terms`;
* собираются словосочетания из двух соседних значимых слов («многодетные
  семьи», «общего пользования»);
* льгота учитывается во **всех годах своего периода действия**;
* в каждом «ведре» (налог × год × регион × категория) остаются `--top` самых
  частых терминов (по умолчанию 400); сводка по России считается точно.

Режим **«отличительные слова категории»** показывает не самые частые, а самые
характерные слова: частота в выбранной категории сопоставляется с частотой в
остальных (log-odds). Так видно, чем льготы для ИП отличаются от льгот для ЮЛ.

Дополнительные слова можно исключить прямо в интерфейсе (поле «Исключить
слова») — это не требует пересчёта.

```bash
python -m fnsportal build-terms --tax tn                    # только категории льготников
python -m fnsportal build-terms --fields category,condition # + условия предоставления
python -m fnsportal build-terms --stopwords "область,район" # разовые исключения
```

## Команды

```
python -m fnsportal init                 создать БД, загрузить справочники и методичку
python -m fnsportal inspect ФАЙЛ…        показать структуру источника и распознанные колонки
python -m fnsportal load-methodology …   перечитать методичку (xlsx или готовый csv)
python -m fnsportal load-rates ФАЙЛ…     загрузить ставки и льготы
python -m fnsportal load-forms ПУТЬ…     загрузить формы статотчётности
python -m fnsportal auto [ПАПКА]         загрузить всё новое из папки (тип файла определяется сам)
python -m fnsportal build-terms          пересобрать словарь для облаков слов
python -m fnsportal demo                 сгенерировать демонстрационные данные
python -m fnsportal stats                что уже загружено
python -m fnsportal serve --port 8000    запустить портал
python -m fnsportal download rates|forms скачать исходники с сайта ФНС
python -m fnsportal update [--apply] проверить и установить обновление
```

Обновление из исходников: `python -m fnsportal update --apply` делает
`git fetch` + `git pull --ff-only` в каталоге проекта. Собранная программа
вместо этого сверяется с релизом «Последняя сборка» на GitHub и при согласии
подменяет свой файл.

Общий флаг `--db ПУТЬ` (или переменная `FNS_DB`) — если нужно несколько баз.

## Структура проекта

```
fnsportal/
  db.py                схема SQLite (регионы, налоги, показатели, факты, ставки, льготы, термины)
  textutil.py          нормализация, стеммер, стоп-слова, определение категории плательщика
  analytics.py         профиль, динамика, средние по субъектам, рейтинги, облака слов
  api.py               HTTP-API и раздача статики
  cli.py               команды
  demo.py              генератор демонстрационных данных
  autoload.py          распознавание и импорт файлов из рабочей папки
  diagnose.py          отчёт о структуре исходников (режим --inspect)
  update.py            проверка и установка обновлений (git / релизы GitHub)
  sources/
    tablestream.py     потоковое чтение csv/xls/xlsx/html/zip/gz (в т. ч. HTML на 3 ГБ)
    rates.py           ETL ставок и льгот, распознавание колонок по алиасам
    forms.py           ETL форм по кодам строк, определение года и региона
    methodology.py     разбор методички: год → код строки → сквозной показатель
    download.py        скачивание с сайта ФНС (с докачкой)
desktop.py             точка входа собранного приложения (exe)
fnsportal.spec         сборка одного exe (PyInstaller)
build.bat              сборка exe на Windows одной командой
reference/             справочники и настройки (правятся вручную)
portal/static/         интерфейс (ECharts + wordcloud, без сборки)
tests/                 pytest
```

### Модель данных

| Таблица | Назначение |
|---|---|
| `region`, `tax` | измерения: территория и налог |
| `indicator` | сквозной показатель формы (стабилен между годами) |
| `indicator_code` | карта «год + код строки + категория → показатель» |
| `fact_form` | значения формы: год × регион × налог × показатель × ЮЛ/ФЛ/всего |
| `rate` | ставки: объект, размер, плательщик, НПА, период действия |
| `benefit` | льготы: категория, вид, размер, условие, основание, ФЛ/ИП/ЮЛ |
| `benefit_term` | предрасчитанные частоты слов для облаков |
| `load_log` | журнал загрузок: что, откуда, сколько строк |
| `imported_file` | какие файлы рабочей папки уже импортированы |

Период действия нормы хранится как `year_from` / `year_to`, поэтому одна
запись НПА не дублируется по годам, а запрос за конкретный год отбирает всё,
что в этом году действовало.

## Если колонки в выгрузке назвали иначе

Соответствие «поле портала → заголовок колонки» вынесено в
`reference/column_aliases.json`. Добавьте свой вариант заголовка в нужный
список — код менять не нужно. Проверить распознавание:

```bash
python -m fnsportal inspect data/raw/rates/ваш_файл.csv
```

Команда печатает найденные таблицы, строку заголовка, распознанные и
нераспознанные колонки.

## Что нужно проверить на реальных данных

Портал собран и протестирован на синтетическом наборе с реальной структурой —
из среды разработки сайт ФНС недоступен (закрыт политикой сети), поэтому
боевые выгрузки в него ещё не заливались. При первой загрузке проверьте:

1. **Заголовки колонок** выгрузки ставок и льгот — командой `inspect`;
   при расхождении дополните `reference/column_aliases.json`.
2. **Коды новых регионов** (ДНР, ЛНР, Запорожская, Херсонская области) в
   `reference/regions.csv` заданы как `93`, `94`, `95`, `96`, Крым — `82` и `91`
   (в выгрузках ФНС встречаются оба). Сверьте с фактическими значениями в
   файле; после загрузки нераспознанные регионы выводятся списком.
3. **Определение года и региона** в формах: загрузчик печатает по каждому файлу
   `регион / год`; если что-то не определилось, укажите `--year` / `--region`.
4. **Единицы измерения** показателей формы берутся из названия и раздела —
   при добавлении новых налогов проверьте `SECTION_UNITS` в
   `sources/methodology.py`.
